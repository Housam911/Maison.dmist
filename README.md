# Maison d'Mist — maisondmist.com

The brand site for **Maison d'Mist** — *Scent Soft Skin*.

A static site: plain HTML, CSS and JavaScript, no build step and no
dependencies. GitHub Pages serves it straight from the `main` branch,
and the domain is registered at Cloudflare.

- **English:** https://maisondmist.com/
- **Arabic:** https://maisondmist.com/ar/

## The two files you edit

| What you want to change | File |
|---|---|
| Phone number, WhatsApp, Instagram, TikTok, Facebook, Telegram, email | `data/site.js` |
| The products shown on the site | `data/products.js` |

Edit either one on github.com, press **Commit changes**, and the live
site updates in about a minute. Nothing else needs touching.

## Everything else

One file holds the full technical record — what is built, how it is

**[docs/TECHNICAL-REPORT.md](docs/TECHNICAL-REPORT.md)** · version `0.10`

## Preview on your own PC

Download the repository and double-click `index.html`. It opens in Edge,
Chrome or Firefox on Windows 10 and 11 and works exactly as it does
online — the product and contact data are plain `.js` files, so no local
web server is needed.
